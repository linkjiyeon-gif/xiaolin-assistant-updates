测试助手 v2.4.33 - 本地 QA 测试工具箱

包含功能：
1. 鼠标连点
   - 左键 / 中键 / 右键
   - 自定义 / 高效 / 极速模式
   - F6-F12 快捷键启动 / 停止
   - 已增加热键防连触保护

2. 网络弱网
   - 指定 IP 延迟
   - 指定 IP 丢包
   - 协议：全部 / TCP / UDP / ICMP
   - 方向：全部 / 出站 / 入站
   - 高级 WinDivert 过滤规则
   - 已修复延迟队列在同时间戳数据包下的稳定性问题

3. 日志抓取
   - 指定 Android 应用包名
   - 检测 ADB 设备
   - 清理 logcat 缓冲区
   - 优先按 PID 抓取
   - 应用未运行时回退为包名关键词过滤，并定时检测 PID，应用启动后自动切换为 PID 抓取
   - 日志保存到 App_Logs
   - ADB 命令已增加超时保护，避免界面长时间卡住

4. 文件比对
   - 比对参考文档（策划文档 / 配置说明）与待比对文件（实际配置文件 / 导出文件）
   - 支持 txt / md / log / json / csv / xlsx / xml / yaml / docx / pdf / 常见代码文件
   - 支持“策划文档 vs 配置文件”专用模式
   - 可抽取并比对配置值、奖励内容、档位、开关状态
   - 新增“翻译源文件 vs 游戏翻译配置表”通用模式
   - 翻译模式支持 xlsx/csv、表头行、数据起始行、主键列、Sheet、语言列映射配置
   - 翻译模式按主键 ID + 语言列逐项比对，输出 ID 缺失/多余、翻译缺失、配置多余、文本不一致、重复 ID、无效 ID、缺少语言列
   - 支持搜索差异、复制差异、导出 Excel 差异报告
   - 翻译模式设置仅在对应模式下显示，语言映射默认折叠，减少滚动卡顿
   - 本地读取、本地比对，不上传、不修改原文件

5. ADB 工具
   - 设备检测，显示 device / offline / unauthorized 状态
   - 读取设备型号、Android 版本、SDK、分辨率、ABI、电量、前台包名和 Activity
   - 一键截图，保存到 Screenshots 目录
   - 一键开始 / 停止录屏，保存到 Recordings 目录
   - 支持安装 APK、启动应用、停止应用、重启应用、清除应用数据、卸载应用
   - 支持识别当前前台应用并自动填入包名
   - 支持操作日志显示、复制、清空

6. APK 信息查看
   - 选择本地 APK 后解析文件名、文件大小、MD5、SHA1
   - 解析包名、versionName、versionCode、minSdkVersion、targetSdkVersion
   - 解析权限列表、ABI 架构、是否 Debug 包、签名信息摘要
   - 优先本地读取 APK，不上传、不执行、不修改 APK
   - 如需更完整 Manifest 信息，可额外配置 aapt.exe 到 PATH

7. 多语言文本质量检查
   - 支持 xlsx / csv 翻译文件或配置表
   - 支持配置表头行、数据起始行、主键列和 Sheet
   - 支持自动识别语言列，也支持手动勾选参与检查语言
   - 支持选择源语言列，用于占位符、特殊符号和长度倍率检查
   - 支持检查空翻译、残留中文、占位符不一致、富文本标签异常、特殊符号异常、文本过长、重复 ID、无效 ID
   - 支持搜索、复制、清空界面结果和导出 Excel 报告
   - 大文件检查在后台线程执行，界面默认最多渲染前 3000 条结果

8. 配置表通用校验
   - 支持 xlsx / csv / json 配置表
   - 支持配置表头行、数据起始行、主键列和 Sheet
   - 支持主键重复、主键为空、必填字段为空、字段缺失、空行检查
   - 支持数值格式、数值范围、布尔值、枚举值、时间格式、时间范围检查
   - 支持奖励格式、引用 ID、min/max 区间配置检查
   - 支持保存 / 加载本地 JSON 校验规则
   - 支持搜索、复制、清空界面结果和导出 Excel 报告
   - 大文件校验在后台线程执行，界面默认最多渲染前 3000 条结果

9. 时间测试
   - 左侧功能栏和首页工具卡片新增“时间测试”入口
   - 支持时间戳转日期时间，自动识别 10 位秒级和 13 位毫秒级时间戳
   - 支持日期时间转秒级 / 毫秒级时间戳，可选择本地时区、UTC、UTC+8 和自定义 UTC 偏移
   - 支持秒、分钟、小时、天、周、月、年互转，月按 30 天估算，年按 365 天估算
   - 支持开始时间与结束时间差值计算，并判断结束时间是否早于开始时间
   - 支持指定时间增加 / 减少固定时长，可直接填写天、时、分、秒并自动换算总秒数
   - 支持结束时间倒计时校验，结束后显示“已结束”
   - 支持当天、次日、本周、下周、本月、下月关键边界时间计算
   - 所有计算均在本地完成，不联网、不上传、不修改系统时间

10. 图标修复
   - 图标资源统一放入 assets 目录
   - 窗口图标、左侧品牌图标、任务栏图标、系统托盘图标、EXE 图标统一使用 assets\app.png / assets\app.ico
   - 旧版根目录 app_icon.png / app_icon.ico 已删除，避免图标资源混用
   - 图标缺失时使用安全 fallback，不影响程序启动

11. 系统托盘
   - 点击窗口右上角 X 时弹出提示，可选择隐藏到托盘、直接退出或取消
   - 最小化窗口时保留在任务栏，不自动隐藏到托盘
   - 托盘右键菜单支持显示主窗口、隐藏主窗口、退出程序
   - 双击托盘图标恢复主窗口
   - 退出程序时会停止连点、弱网、ADB 日志抓取、ADB 录屏，并释放托盘图标

文件说明：
- xiaoxin_assistant.py：主程序源码
- app\：文件比对、ADB 工具、APK 信息解析、日志分析、多语言检查、配置表校验和时间测试模块
- assets\app.png：窗口 / 托盘图标 PNG
- assets\app.ico：窗口 / 任务栏 / EXE 图标 ICO
- requirements.txt：运行依赖列表
- run.bat：预览运行脚本
- build_exe.bat：EXE 打包脚本，窗口不会自动关闭
- build_installer.bat：Windows 安装程序打包脚本，会调用 build_exe.bat 和 Inno Setup
- installer\setup.iss：Inno Setup 安装包配置脚本
- INSTALL_AND_FIRST_USE.txt：安装、打包和分发说明
- Catch_TinyWar_Log.bat：原始日志抓取 bat，仅保留作参考，主程序不依赖它

ADB 说明：
- 日志抓取和 ADB 工具功能需要电脑可以执行 adb
- 推荐安装 Android platform-tools，并把 adb 加入系统 PATH
- 也可以把 adb.exe 放到本目录，程序会优先使用本地 adb.exe
- 如果本目录存在 adb.exe，build_exe.bat 会尝试一起打入 EXE

预览运行：
1. 完整解压 zip
2. 双击 run.bat
3. 网络弱网功能需要点击左下角“管理员重启”

打包 EXE：
1. 完整解压 zip
2. 双击 build_exe.bat
3. 第一次会创建 .venv_build 并安装依赖，可能需要几分钟
4. 成功后查看 dist\XiaoLinAssistant.exe

打包 Windows 安装程序：
1. 先安装 Inno Setup 6
2. 完整解压 zip
3. 双击 build_installer.bat
4. 脚本会先调用 build_exe.bat 生成 dist\XiaoLinAssistant.exe
5. 然后调用 Inno Setup 生成安装包
6. 成功后查看 Output\XiaoLinAssistant_Setup_v2.4.33.exe
7. 安装程序默认安装到当前用户目录，不强制管理员权限
8. 安装包支持开始菜单快捷方式、可选桌面快捷方式、卸载程序和安装后启动

如果 build_exe.bat 仍然闪退：
1. 不要在压缩包预览窗口里双击
2. 完整解压到英文路径，例如 D:\xiaolin_assistant
3. 右键 build_exe.bat，选择“以管理员身份运行”
4. 如果生成了 build_log.txt，把它发给我

注意：
- 仅支持 Windows
- 网络弱网需要管理员权限
- 弱网底层依赖 pydivert / WinDivert
- 文件比对和多语言检查依赖 python-docx / openpyxl / PyPDF2 / PyYAML
- ADB 工具需要 adb.exe 或 Android platform-tools
- APK 基础信息可本地解析；完整 Manifest 建议配置 aapt.exe
- 系统托盘依赖 pystray
- 建议 Python 3.10-3.13
