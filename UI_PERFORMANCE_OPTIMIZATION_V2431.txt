QA 测试工具盒 v2.4.31 - UI 性能优化说明
=======================================

本次优化不改变业务校验、文件解析、ADB/iOS 命令和报告格式。

主要调整：

1. 功能页改为首次访问时创建，后续切换直接复用缓存页面。
2. 文件比对页的“数值配置比对”和“翻译比对”设置区改为按模式创建。
3. CustomTkinter 字体对象统一缓存复用，减少大量重复字体实例。
4. openpyxl 改为实际读取 xlsx 时再导入。
5. pynput 改为首帧显示后在后台初始化。
6. 系统托盘、热键和状态轮询延后到主窗口首帧之后启动。
7. 主内容区、侧边栏、右侧设置栏不再使用 CTkScrollableFrame 整体滚动。
8. ADB 日志任务与运行日志改为局部 Tab，表格和文本框独立滚动。
9. 多语言选择区改为固定六列网格，避免嵌套 Canvas 滚动。
10. 弱网页改为双列紧凑布局，确保 1280x760 下无需整页滚动。
11. 移除 16ms 滚轮拦截及页面构建后的强制刷新，降低滚动跳动和拖影。
12. 文件比对改为“文件与模式 / 专项设置 / 比对结果”固定 Tab，翻译高级设置展开时自动隐藏基础区。
13. 配置校验的高级字段规则与检查开关拆分为独立 Tab，避免最小窗口下裁切。

本机静态 GUI 冒烟测试结果（仅用于对比，不代表所有电脑）：

- 文件比对页首次创建：约 1857ms -> 354ms
- ADB 工具页再次进入：约 769ms -> 93ms
- 文件比对页再次进入：约 1395ms -> 84ms
- 配置校验页再次进入：约 2454ms -> 82ms
- 多语言检查页再次进入：约 2062ms -> 112ms
- 主模块导入平均耗时：约 1182ms -> 745ms

说明：

- 配置校验、多语言检查等大型页面首次访问仍需创建较多控件，首次进入会比普通页面慢。
- 页面创建完成后会保留在内存中，以少量内存占用换取后续快速切换。
- 已通过 1280x760 最小窗口逐页边界检查，未发现可见控件越界。
- 建议继续在 Windows 真机 100% / 125% / 150% 显示缩放下验证主题切换、连续切页、ADB 日志和 iOS 日志页面。
