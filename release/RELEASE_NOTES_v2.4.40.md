# 测试助手 v2.4.40

本次更新支持网络弱网同时拦截多个 IP，优化日志抓取时的界面流畅度，并在安装包中内置 iOS 工具。

## 网络弱网

- 目标 IP 支持填写多个，可用逗号、分号或空格分隔，重复项自动去除。
- 支持 IPv4、IPv6、网段（如 10.0.0.0/24）和 IP 范围（如 1.1.1.1-1.1.1.20）。
- 运行日志显示目标数量和目标列表。
- 启动前校验过滤规则；单条规则最多约 120 个 IP 或 60 个网段/范围，超出时直接提示原因。

## 流畅度优化

- 抓取 ADB / iOS 日志和监听全局热键时，后台线程不再逐行、逐键跨线程读取界面变量，减少日志量大时的卡顿。
- iOS 实时日志改为批量写入界面。
- 修复 iOS 日志显示满 3000 行后，每来一行就删除 200 行的问题。
- 日志分析结果合并刷新，并确保最后一批命中会显示；不在日志分析页时只记录，切换回来时再刷新。
- 网络弱网、ADB 日志、ADB 工具的运行日志框最多保留最近 2000 行，避免长时间运行后变慢。

## 安装包

- 安装包内置 libimobiledevice iOS 工具，安装后无需额外配置即可使用 iOS 日志。

## 验证

- 新增多 IP 解析、规则生成和超长提示等测试。
- 完整回归测试共 66 项，63 项通过，3 项按条件跳过，无失败。
