# 测试助手 v2.4.39

本次更新重点增强“网络弱网”模块的稳定性、真实性和操作安全性。

## 弱网调度与稳定性

- WinDivert 规则自动增加 `!impostor` 重注入保护，避免已发送数据包被重复捕获。
- 延迟队列同时限制数据包数量和累计字节数，防止高流量、长延迟场景下内存持续增长。
- 默认按照方向、协议、源/目标 IP 和端口识别连接，同一连接在启用抖动时仍保持数据包顺序。
- 不同连接独立计算延迟，并通过公平调度避免单个大流量连接长期阻塞其他连接。
- 接收失败、发送失败、队列溢出、模拟丢包和停止取消分别处理并统计，运行异常后自动释放句柄、线程和队列。

## 新增弱网场景

- 支持“基础单向延迟 ± 抖动”，抖动不会产生负延迟。
- 支持主动设置数据包乱序概率，默认关闭，不再由普通延迟抖动隐式产生乱序。
- 支持上行和下行分别限速，可选择 Kbps 或 Mbps，填写 0 表示不限速。
- 支持突发丢包，可设置触发概率和每次连续丢包数量，并与随机丢包分别统计。
- 支持自动停止时间和“立即恢复网络”，测试结束或异常时可以快速恢复正常网络。

## 界面与统计

- 参数拆分为“基础设置”和“进阶模拟”，增加移动网络、海外高延迟、低带宽和突发丢包预设。
- 使用说明和运行日志独立展示，使用说明支持折叠和展开。
- 明确说明当前延迟为单向延迟，并展示上下行同时生效时的预计额外 RTT。
- 新增随机丢包、突发丢包、乱序、限速等待、队列字节数、上下行实时速度、剩余时间等统计。
- 全流量范围、极高丢包、主动乱序、极低带宽和超高延迟启动前增加安全确认。

## 验证

- 新增同连接保序、跨连接独立调度、100% 乱序、上下行限速、突发丢包、自动停止和紧急恢复等测试。
- 完整回归测试共 58 项，全部通过。
