# 测试助手 v2.4.36

本次更新重点完善多语言文本质量检查，并新增 ADB 设备分辨率标识。

## 多语言检查

- 支持多文件语言字典和自由选择源语言，增强多 Sheet 翻译整合表及大文件识别。
- 增加读取与检查进度反馈，避免大文件处理时被误认为卡死。
- 优化占位符、富文本标签、换行和特殊符号检查，减少边界误报与重复问题。
- 优化等级、序数、范围、连字符、Excel 日期和本地化数值比较规则。
- CN 源文本问题独立检查并去重，不再按每种目标语言重复输出。
- 整列未翻译改为语言覆盖状态汇总，个别空翻译继续逐行检查。
- 报告按明确问题、源文本问题、需人工确认和语言覆盖范围分类，所有页面自动开启筛选并冻结表头。
- 修复主键 ID 导出带 `.0` 以及 `#NAME?` 被 Excel 识别为错误单元格的问题。

## ADB 工具

- 设备列表和当前设备详情新增分辨率显示。
- 支持 Physical size 与 Override size，存在 Override 时展示当前生效分辨率。
- 多设备按 Serial 分别查询，失败时自动使用 dumpsys display 备用方式。
- 增加按 Serial 缓存、断开清理和主动刷新机制，分辨率查询不阻塞主界面。

## 稳定性

- 完善异常处理和检查结果统计口径。
- 已完成商业化比对、配置表校验、多语言检查、ADB 工具和在线更新回归测试。
