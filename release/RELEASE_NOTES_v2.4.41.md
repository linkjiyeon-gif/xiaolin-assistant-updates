# 测试助手 v2.4.41

本次更新重做了整体界面，优化了启动和切换页面的流畅度，并改进了网络弱网、日志抓取、iOS 日志、时间测试和鼠标连点的使用体验。

## 界面改版

- 统一字号、圆角、间距和按钮样式；左侧导航改用 Windows 自带图标，选中页面高亮显示。
- 首页工具卡片整张可点击；“最近状态”改为“正在运行”，只列出运行中的任务，点击可跳转，并修复了状态不刷新的问题。
- 右侧设置栏精简，去掉重复和不会变化的信息。
- 文件比对、配置表校验、多语言检查不再迭代，移到导航和首页的最后。

## 流畅度

- 启动时先在后台排版完成再显示窗口，打开时不再看到界面逐块刷新。
- 切换页面时只更新变化的导航项，切回已打开的页面更快。
- 停在网络弱网、ADB 工具、鼠标连点页时，状态不变就不再周期性重画，避免卡顿。

## 网络弱网

- 目标 IP 改为多行输入框，可直接粘贴一列 IP；下方实时显示识别结果、IP 标签和格式错误。
- 输入框在编辑时自动展开，离开后收起，把空间留给运行日志。
- 高级规则移到“进阶模拟”页；使用说明改为弹窗，运行日志占满整行。

## 日志抓取、ADB 工具与 iOS 日志

- 首次打开页面时自动检测设备，只有一台设备时自动选中；iOS 页自动检测内置工具和设备。
- 日志抓取：主按钮“开始抓取 / 停止全部抓取”，新增“识别前台应用”、最近使用的包名和实时日志预览。
- iOS 工具路径配置收进“自定义路径”，默认只显示一行工具状态。
- 日志分析修改关键字和上下文行数后自动生效，不再需要点“应用配置”。

## 时间测试

- 新增美西、美东、伦敦、中欧、日本 / 韩国、悉尼等时区，自动处理夏令时。
- 输入后自动出结果；点击结果中的任意一行即可复制该值；顶部显示当前时间和时间戳，点击即可复制。
- 每个页签说明“输入时间所在时区”，结果第一行写明换算关系；自定义偏移只在需要时显示。
- 修复跨夏令时切换时时间差和倒计时相差 1 小时的问题；修复边界时间留空时按本机时区计算的问题。

## 鼠标连点

- 用按钮启动时先倒数 3 秒，便于把鼠标移到目标位置；热键启动仍立即开始。
- 支持“点击 N 次后停止”和“运行 N 秒后停止”，并显示已点击次数、运行时长和实际速度。

## 验证

- 完整回归测试共 84 项，81 项通过，3 项按条件跳过，无失败。
- 各页面在深色、浅色主题和最小窗口 1280×760 下逐一截图检查。
