## v2.4.32

测试助手 / QA 测试工具盒的首个 GitHub 在线更新引导版本。

### 新增

- 基于 GitHub Releases 的在线更新功能。
- 启动完成后后台检查更新，也可在右侧设置栏手动检查。
- 支持版本说明、下载进度、取消下载和稍后安装。
- 安装前校验安装包大小与 SHA-256。
- 独立更新器等待主程序安全退出后静默安装，并自动重新启动。

### 保留修复

- UI 页面缓存、启动加载和滚动拖影优化。
- 最小化后从任务栏关闭时，关闭确认框可正常恢复和操作。
- 商业化配置比对、配置表校验和多语言检查回归修复。

> v2.4.32 是在线更新引导版本，需要先手动安装一次。从后续版本开始即可在工具内直接在线升级。
