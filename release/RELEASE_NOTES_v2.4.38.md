# 测试助手 v2.4.38

本版本重点完善多语言文本质量检查，降低重复表头、流程控制行、自然语言词汇、Excel 日期格式和本地化数字表达造成的误报，并优化检查范围与报告分类。

## 主要更新

- 根据文件名中的语言代码组合推荐本次目标语言，最终仍以用户勾选为准。
- 报告中记录实际源语言与目标语言范围，未选语言不参与统计。
- 通用识别并排除数据区域中的重复表头、子表头和字段说明行。
- 非文本流程控制行在源文和译文均为空时不再误报。
- TODO/TBD/FIXME 改为完整标记匹配，`todo`、`todos`、`metodo` 等自然词汇不再误报。
- Excel 单元格保留原始值、显示值、数据类型和格式；疑似短编号被转成日期时仅输出一次源文本格式问题。
- 完善中文、Indonesian、Italian、Turkish 数字词、月份、范围及近似数量标准化。
- 区分正常换行、转义换行以及疑似写反的 `n/`、`/n`。
- 完善 `[e]` 等注册标签的语法与结构检查，普通方括号文本不作为标签。
- 不同源文本复用相同译文调整为默认关闭的低置信度辅助分析，不计入明确错误。
- 报告拆分明确问题、源文本问题、需人工确认、语言覆盖、译文复用和白名单等分类，所有明细页自带筛选。

## 兼容性说明

- 保留真实空翻译、缺失 ID、占位符、中文残留、标签和换行差异的检测能力。
- 不判断翻译语义是否准确。
- `EN Final` 等不含 Translation/翻译标记的表头兼容问题尚未包含在本版本中。

## 验证

- 35 项自动化测试全部通过。
- 历史商业化比对、配置表校验及多语言检查样例回归通过。
